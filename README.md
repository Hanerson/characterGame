# ⛵ 忒修斯之船 (Ships of Theseus)

> *"若所有木板皆已被替换，愿此处的文字仍是你的锚点。"*

一个基于 React + Vite 构建的交互式网络叙事项目。它**不是一个游戏**，而是一组真实存在的校园网站——至诚大学的门户、课程主页、匿名论坛、档案检索与诊断系统。所有违和感都以"这所学校真实存在"的方式呈现。

---

## 🎭 项目概念

**ARG 原则：世界内部不承认玩家的存在。**

- **表面层**：2010年代风格的至诚大学校园网站群——门户首页、编译原理课程、教学资源库、师资队伍
- **中间层**：一个从2001年运行至今的校内匿名论坛，26位"参与者"讨论忒修斯之船悖论
- **深层**：诊断系统的日志与数据库记录——它们读起来像是机器自己在说话
- **真相由访问者自己拼凑**：没有任何页面会直接告诉你结论。论坛不会说"所有用户IP相同"，课程页不会说"这是模拟"。你只是在浏览一个逐渐变得不对劲的校园网。

### 具体规则

1. **不暗示游戏环境**：页面中不出现"线索""关卡""发现""进度"等表述。用户界面不分析任何内容。
2. **拒绝高位观察者评价**：诸如"所有参与者是同一人""IP地址全都一样"这类结论，只存在于系统日志、数据库查询、论坛帖子等**世界内的材料**中，由访问者自行读出。
3. **工程层是唯一允许"说破"的层**：诊断系统、管理面板、数据库错误——这些是机器自己的输出，它们可以暴露真相。

## 🗺️ 路由结构

| 路由 | 页面 | 说明 |
|------|------|------|
| `/` | 门户首页 | 至诚大学校园门户（新闻、公告、快速链接） |
| `/course` | 编译原理课程主页 | 至诚大学CS304课程（页面数据存在异常） |
| `/course/resources` | 教学资源库 | 文件下载站——多数文件只有索引记录 |
| `/course/faculty` | 师资队伍 | 含林远老师的历史记录 |
| `/dep` | TexiusiShip BBS | 校内匿名论坛——环境叙事的核心 |
| `/archives` | 档案检索 | 校园网档案目录（部分档案需先找到访问途径） |
| `/archives/:docId` | 档案阅读器 | 按文档类型自动切换 5 种渲染风格 |
| `/system/logs` | 诊断系统 | 系统日志 + 交互式终端（含 `leaks` / `timeline` 命令） |
| `/system/console` | 管理面板 | 最深层——需要绕过认证；完整记录仅对访问过主要站点的会话开放 |
| `/*` | 404 | 错误页面也包含微妙异常 |

所有页面运行在一个**浏览器外壳**中（地址栏、收藏夹、状态栏）——因为访问者就是一台真实机器上的浏览者。

## 🔒 访问控制（世界内规则，非游戏门槛）

某些内容在站点内部有自然的访问限制。这些限制以"权限不足""该时段的记录尚未对外开放"等世界内语言呈现：

- 医疗档案（MRI / 伦理驳回）需先在诊断系统中确认其恢复记录
- 《1992年论文》需先阅读相关医疗记录
- BBS 终末时段（2023-2026）主题需先访问诊断系统
- 管理面板的完整实验记录需访问过主要站点区域

访问历史仅保存在浏览器本地（`localStorage`），不向访问者展示任何进度。

### 核心技术特点

- **纯前端模拟**：所有"服务器响应"、"数据库查询"、"下载失败"均为前端模拟
- **环境叙事**：故事通过错误消息、页面注释、日志、档案等世界内材料呈现
- **2010年代UI**：浏览器外壳 + 各站点独立风格，宋体字体，凸起/凹陷边框
- **浏览器外壳**：地址栏（含按 IP 访问的诊断系统）、收藏夹、状态栏

## 📖 环境叙事设计

### 关键异常分布

1. **门户首页**：一条2001年的离任说明、一条"长期未归还"的图书通知、空空的友情链接
2. **课程主页**：课程名称出现"？"乱码，统计面板有一条"孤立记录"，公告时间线异常地长
3. **教学资源**：文件下载失败——它们只有索引记录
4. **师资队伍**：林远老师2001年"离职"，但其创建的进程至今运行
5. **论坛BBS**：26个匿名账号的讨论，随时间推移逐渐失序
6. **诊断系统**：日志与数据库查询显示"1条记录、26个别名"
7. **管理面板**：绕过后可见"忒修斯协议"实验记录——你（访问者）是第27个会话
