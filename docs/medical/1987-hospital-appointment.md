# XX大学附属仁济医院报到通知书

| 字段 | 内容 |
|------|------|
| 年份 | 1987 |
| 类型 | 人事档案 |
| 人物 | 林远 |

---

**编号：** 仁医人〔1987〕第49号

林远同志：

经医院研究决定，并报请上级主管部门批准，同意接收您为我院神经外科 研究实习员（专业技术十二级）。请您于**1987年8月25日**前携带以下材料来我院人事处办理报到手续。

**报到须知：**

- 本人身份证及户口簿复印件
- 毕业证书及学位证书原件
- 近期一寸免冠照片三张
- 党（团）组织关系介绍信
- 粮油关系转移证明

**薪资待遇：**

| 项目 | 金额 |
|------|------|
| 基本工资 | 人民币78元/月 |
| 粮价补贴 | 5元/月 |
| 奖金 | 视科室效益及个人考核情况发放 |

**其他说明：**

- 报到后试用期为六个月，期满考核合格者转正定级；
- 医院提供集体宿舍床位一张（需自备被褥），月租金8元。

欢迎您加入仁济医院，希望您在未来的工作中，发扬刻苦钻研、精益求精的精神，为我院神经外科的发展贡献力量！

**XX大学附属仁济医院 人事处（公章）**
**1987年8月1日**

抄送：神经外科、总务科、财务科
存档：院办、人事处

---

**手写便签（附后，科室主任笔迹）：**

> 小林：
> 欢迎。别着急，先熟悉环境。
>
> 张
> 1987.8.3

---

*档案说明：这是林远进入医疗系统的第一份正式文件。25岁的他进入神经外科，以"研究实习员"身份开始职业生涯。科室主任的手写便签显示出对这位新人的善意。这也是林远人生中最后一个"正常"的起点——一切尚未开始，一切尚有可能。*
